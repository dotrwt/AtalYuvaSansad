## Overview

**Atal Yuva Sansad** is a youth-led parliamentary simulation platform dedicated to familiarising young citizens with the functioning of India's democratic institutions. Rooted in the constitutional philosophy of former Prime Minister **Atal Bihari Vajpayee**, the forum prioritises structured debate, legislative reasoning, procedural discipline, and accountable representation over performative politics.

The event takes place over three days at **Kiddy's Corner Hr. Secondary School, Shivpuri Link Road, Gwalior** bringing together delegates from across institutions to engage with governance as a constitutional responsibility.

Website is live on : <a href='https://dotrwt.github.io/AtalYuvaSansad/'>dotrwt.github.io/AtalYuvaSansad/</a>

## Committees

Six committees spanning domestic legislation, international diplomacy, student governance, and press freedom.

| Committee     | Full Name                           | Agenda                                                                                                                                                             |
| ------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Lok Sabha** | The Indian Parliament               | Deliberation on Communalism in India: Examining the Role of Media, Social Media Regulation, and Misinformation in Shaping National Harmony                         |
| **UNSC**      | United Nations Security Council     | Addressing Threats to Sovereignty: The Implications of Unilateral Military Actions, Extraterritorial Operations, and Attempts at Annexation on International Peace |
| **UNHRC**     | United Nations Human Rights Council | The Case of Israel                                                                                                                                                 |
| **BMS**       | Bharatiya Mahila Sansad             | Review of Child Sexual Offences and Marital Rape in India: Abuse of Power with Reference to the Unnao Incident of 2019                                             |
| **AISLM**     | All India Student Leaders' Meet     | Deliberation on the Shrinking Democratic Space in Contemporary India                                                                                               |
| **IPC**       | International Press Corps           | Journalism, Photography & Caricature                                                                                                                               |

## Project Structure

```
AtalYuvaSansad/
├── index.html          # Single-page website
├── styles.css          # Theme, layout, and component styles
├── script.js           # Scroll-reveal animations, mobile navigation
└── assets/             # Images, illustrations, and committee seals
```

**Tech Stack:** Vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies. Runs directly in any modern browser.

### Running Locally

```bash
git clone https://github.com/dotrwt/AtalYuvaSansad.git
cd AtalYuvaSansad
open index.html
```
